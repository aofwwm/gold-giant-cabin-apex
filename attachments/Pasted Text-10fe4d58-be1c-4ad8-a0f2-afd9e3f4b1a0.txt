Please change ONLY the visual theme of the existing TODAY mode in Kairos.

IMPORTANT:
Do NOT redesign Today.
Do NOT change its layout, data, logic, routing, timeline behaviour, Replan logic, Supabase logic, or other modes.

This task is purely to give TODAY its own distinct colour identity.

CURRENT PROBLEM:

Today currently feels too visually close to the red/vermilion work modes.

That is not appropriate because Today is the umbrella / central intelligence layer that contains:

- Meet
- Makan
- Team Out
- Family
- Dating
- Tasks
- Appointments
- Free time
- Travel

Today should feel neutral, calm and intelligent.

==================================================
NEW TODAY THEME
==================================================

Use a:

MIDNIGHT INDIGO + PERIWINKLE

colour system.

Suggested palette:

Primary indigo:
#6F7FD8

Periwinkle accent:
#9AA8FF

Slate blue:
#66738F

Pale ice highlight:
#C8D3FF

Background:
keep the existing Kairos dark espresso / near-black background

Text:
keep warm ivory / off-white

Optional deeper indigo for darker surfaces:
#4F5FAF

==================================================
DESIGN INTENT
==================================================

Today should feel:

- calm
- intelligent
- premium
- temporal
- organised
- slightly futuristic
- central / overarching

It should NOT feel:

- corporate blue
- generic SaaS
- bright royal blue
- neon
- cyberpunk
- overly colourful

Think:

“quiet command centre”

rather than:

“tech dashboard”

==================================================
CSS / THEME TOKENS
==================================================

Implement this using the existing mode-aware theme token system.

Do NOT hardcode random indigo values throughout multiple components.

Create / update proper Today theme tokens.

Example concept:

--today-primary: #6F7FD8;
--today-accent: #9AA8FF;
--today-secondary: #66738F;
--today-highlight: #C8D3FF;
--today-deep: #4F5FAF;

Then map Today components to these tokens.

If the app already has theme variables, integrate into that system instead of creating duplicate systems.
